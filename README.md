# QuickLinks

자주 여는 폴더·파일·웹 주소를 바탕화면 위젯에 모아 두고 클릭 한 번으로 여는 Windows 11용 프로그램입니다.

## 쓰는 법

- **추가**: 탐색기의 폴더·파일이나 브라우저 주소창의 주소를 위젯에 끌어다 놓습니다. 또는 `＋`를 누르고 경로·주소를 붙여넣은 뒤 `Enter`를 누릅니다(`폴더…`·`파일…` 버튼으로 골라도 됩니다). 위젯에서 `Ctrl+V`를 눌러도 추가됩니다.
- **열기**: 항목을 클릭합니다. `Ctrl+Enter`나 우클릭 → "파일 위치 열기"는 상위 폴더에서 그 항목을 선택한 상태로 엽니다. 가운데 클릭은 경로를 복사합니다.
- **여러 개 선택**: `Ctrl`+클릭은 하나씩 더하거나 빼고, `Shift`+클릭(또는 `Shift+↑↓`)은 범위를 선택합니다. `Ctrl+A`는 보이는 항목 전부입니다. 선택한 채로 끌면 함께 옮겨지고, `Enter`(열기)·`Delete`(제거)·`Ctrl+C`(경로 복사)·우클릭 메뉴가 선택한 전부에 적용됩니다.
- **정리**: 항목을 끌어서 순서와 그룹을 바꿉니다. 그룹 제목 위에 놓으면 그 그룹으로 들어갑니다(펼친 그룹은 맨 위, 접힌 그룹은 맨 끝). 우클릭하면 이름 바꾸기, 경로 수정, 그룹 이동, 목록에서 제거 메뉴가 있습니다. 그룹 제목을 우클릭하면 새 그룹, 이름 바꾸기, 위로·아래로, 그룹 삭제가 있습니다.
- **검색**: 위젯에서 바로 글자를 입력하면 이름·경로로 걸러집니다. `↑`·`↓`로 고르고 `Enter`로 엽니다.
- **키보드**: `F2` 이름 바꾸기, `Delete` 목록에서 제거, `←`·`→` 그룹 접기·펼치기, `Esc` 검색 지우기 → 위젯 숨기기.
- **실행 취소**: `Ctrl+Z` 되돌리기, `Ctrl+Y`(또는 `Ctrl+Shift+Z`) 다시 실행. 추가·제거·이동·이름 바꾸기·경로 수정·그룹 변경을 최근 50번까지 되돌립니다. 그룹 접기·펼치기는 되돌리지 않습니다. 목록 빈 곳을 우클릭해도 있습니다. 검색칸·입력칸 안에서는 그 칸의 글자를 되돌립니다.
- 머리글 버튼: 📌 항상 위, `＋` 추가, ⚙ 설정, `✕` 트레이로 숨기기. 트레이 아이콘을 클릭하면 다시 나타납니다.
- 트레이 아이콘 우클릭: 항상 위, 투명도 n%, 설정, 종료.
- **설정 창**(⚙ 또는 트레이 "설정"): 여는 방법(한 번/두 번 클릭), Windows 시작 시 실행, 테마(Windows 설정 따르기/라이트/다크), 시계(끄기 / 큰 숫자 / 한 줄 / 아날로그 카드), 시계 위치(위: 제목 아래 / 아래: 목록 아래), 24시간제, 초 표시. 바꾸면 바로 적용됩니다. 시계 부분을 잡고 끌어도 위젯이 옮겨집니다.
- "투명도 n%"를 누르면 슬라이더가 떠서 0~50%를 1% 단위로 조절합니다(끌기, 휠, `←→` 1%, `PgUp/PgDn` 10%, `Enter` 확정, `Esc` 취소). 위젯 위에서 `Ctrl`+마우스 휠로도 1%씩 바뀝니다. 휠을 위로 굴리면 진해지고(덜 투명), 아래로 굴리면 투명해집니다.

"목록에서 제거"는 바로가기만 지웁니다. 실제 파일·폴더는 건드리지 않습니다.

경로를 찾을 수 없는 항목(꺼진 NAS 등)은 흐리게 표시되고, 열면 위젯 아래에 "찾을 수 없음" 막대가 뜹니다.

## 설정 파일

`%APPDATA%\QuickLinks\QuickLinks.ini` (UTF-16). 위치·크기, 항상 위, 여는 방법, 그룹과 항목이 들어 있습니다. 직접 고치려면 QuickLinks를 종료한 뒤 고치세요(실행 중에는 변경할 때마다 덮어씁니다).

## 실행 환경

`QuickLinks.exe` 하나만 있으면 됩니다(설치·런타임 불필요). Windows 11 기준으로 만들었고, Windows 10(1607 이상)에서는 Windows 10 글꼴(Segoe UI, Segoe MDL2 Assets)로 자동으로 바꿔 그립니다. Windows 10에서는 창 모서리가 둥글지 않습니다.

## 빌드

Visual Studio 2022(또는 Build Tools)의 C++ 워크로드가 필요합니다.

```bat
build.bat
```

결과: `build\QuickLinks.exe` (단일 exe, 설치 없음). 관리자 권한으로 실행하지 마세요. 일반 탐색기에서 끌어다 놓기가 막힙니다.
